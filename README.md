I'm a final-year **Mathematics and Computing** student at **Indian Institute of Technology (Banaras Hindu University), Varanasi**. I'm interested in the intersection of **mathematics, machine learning, software engineering, and open-source development**.

I'm also **neurodivergent and live with ADHD**. Some days, staying focused and consistent is difficult. But I keep showing up, learning, breaking things, fixing them, and trying again. I don't want my journey to look perfect; I want it to be real.
